# R7 / R8: extrusion subtraction

The two JSON fixtures are the original compressed modeling solids supplied by the
CAD app on 2026-09-08. They retain the original NURBS and equivalent four-quarter
conic representations. No geometry conversion or tolerance change is required.

## Changes

- Native exact and nearest searches on extruded curves and affine B-spline/NURBS
  rulings project onto 51 sampled rulings before the existing Newton solve.
  Spline searches collapse the linear coefficients once per query and share each
  nonlinear basis evaluation between both ruling endpoints. Explicit hints bypass
  presearch. Unsupported knots/weights, invalid ranges, and degenerate rulings use
  the existing grid. There is no persistent geometry cache or representation change.
- `subtract_with_effect(target, cutter, tol)` returns `SubtractionResult { solid,
  removed_material }`. The flag comes from excluded target pieces and cutter faces
  inside the target in the same classification pass. Coincident contact is excluded.
  Empty operands, complete consumption, cavities, and disconnected shells are tested.
  Only the selected boolean boundary is fitted.
- R8 was a tessellation error: exact horizontal-cap integration gives approximately
  46,009.72587 mm³ for the conic boolean result, agreeing with the independent
  cross-section reference. A surface grid subdivided only around an extrusion can
  lose entire rulings to trimming. The resulting long interior diagonals form triangle
  fans across the curved wall; tighter boundary sampling alone does not fix them.
  The mesher now refines those interior diagonals against the existing chord tolerance,
  preserving shared boundary samples and constraints. This refinement applies to
  grids subdivided in only one direction; existing two-dimensional grids retain their
  meshing path, including singular sphere patches.
- Reversed processor curve divisions now reverse their parameter array together with
  the sampled points, preserving parameter/point correspondence in both 2D and 3D.

## Reference volumes

Before the correction, conics produced 46,116.448870 mm³. Both corrected results
satisfy the original 1 mm³ allowance around 46,009.72603 mm³; exact-cap integration
satisfies a separate 0.001 mm³ allowance. Each timed result retains 22 faces, and
validation checks one connected body, closed oriented topology/meshes, and operand
nonmutation. The regression also rebuilds the target with sequential conic unions
before subtraction and reflects the operands to cut in the opposite Z direction.

cargo test --release --locked -p truck-shapeops --test subtract_effect
cargo test --release --locked -p truck-geometry --test ruled_search --test processor
cargo test --release --locked -p truck-meshalgo --test tessellation
