# R10: sequential fillet contact-circle panic

Status: panic fixed; the equal-radius sequential corner remains unsupported and
returns `None`. This is not a claim that the requested second 1 mm fillet now builds.

## Reproduction and cause

`R10-first-fillet-solid.json` is the unchanged reported input to Fillet 2: a
70 × 70 × 70 mm cube after a 1 mm fillet on one vertical edge. SHA-256:
`05f83e4d83cf48a08100d1c97ad289089b50cc8cc2b5040f54b3b9eafbb98c58`.
The test resolves the same top/front seed geometrically and reproduces the app's
open, three-edge tangent chain, including the quarter-circle over the first fillet.
The supplied no-panic test failed on parent `7f792445` with the reported invalid
contact-circle Newton step. The input/wire control passed.

On the cylindrical part, let the first radius be R and the second radius be r.
The rolling-ball center and top-plane contact trace a circle of radius R − r.
When r = R, the top contact curve collapses to one point. The geometric limit is a
spherical corner, but this chain implementation requires two regular contact curves
and one four-sided patch per chain edge. Building that limit requires a different
corner topology, beyond recovering a missed Newton solution. When r > R, the local
offset reverses orientation; the previous code could return a topological solid
whose tessellated boundary was not closed. Both cases now return normal failure.

This restriction concerns rounding a convex cylindrical fillet's rim at a
perpendicular planar cap. It does not prohibit all sequential fillets or all
equal-radius multi-edge operations: the existing planar multi-edge fillet builder
has its own supported spherical junctions.

## Changes

- Adaptive contact-circle queries propagate failure through the existing `Option`
  API, just like the initial samples.
- Singular matrix inversions, nonfinite contact/step data, invalid Newton residuals
  and failed tangent frames return `None` instead of unwrapping or asserting.
- The approximation checks offset orientation at converged contact points and
  rejects collapsed or folded offsets. Intermediate Newton iterates remain free
  to cross a fold while converging, preserving existing contact searches.
- The solid and wire APIs document the restriction. No catch-and-ignore-panic
  wrapper or application workaround was added.

## Tests

The original input and geometric selection remain unchanged. Tests cover:

- The supplied control and no-panic/input-nonmutation regression, explicitly
  expecting `None` for equal radii.
- Successful second radii 0.2, 0.5 and 0.8 mm on the supplied 1 mm first fillet.
- Cube sizes 10 and 70 mm, first radii 1 and 2 mm, second/first radius ratios
  0.5, 1 and 1.2, both first-edge orders and both wire directions (48 combinations).
- For successful results: closed oriented topology and tessellation at 0.001 mm,
  analytical volume, complete consistent face history, and unchanged inputs.
  For equal/larger radii: `None` and unchanged inputs.
- An approximation whose initial three contact circles succeed but whose first
  adaptive midpoint fails; singular contact planes and invalid contact circles.

Run them with:

```sh
CARGO_PROFILE_TEST_OPT_LEVEL=1 RAYON_NUM_THREADS=2 cargo test --locked \
  -p truck-geometry -p truck-shapeops -p truck-meshalgo
RAYON_NUM_THREADS=2 cargo test --release --locked -p truck-shapeops \
  --test R10-sequential-fillet -- --nocapture --test-threads=1
```
