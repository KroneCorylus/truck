# Mixed disjoint chamfer components

A tangent circular rim and an isolated straight edge can be chamfered separately, but their combined request failed because disjoint components always used the wire constructor. One-edge components now fall back to the existing single-edge constructor for supported construction/geometry/topology failure codes. The fallback restores side distances to current-shell edge orientation. OutsideNeighbour is not retried. Selected-edge survival, generated-bevel collision guards and final correspondence against the original input remain unchanged. The splitter returns before application for fewer than two components, so the single-edge API cannot recurse through this fallback.
