# Separate open fillet contours and shared supports

Separate fillet contours previously had to be closed and use distinct support faces. The fallback now groups nonbranching open or closed tangent chains in original shell order. Original supports may be trimmed by more than one component, while remaining selected edges must survive and earlier generated fillets must remain unchanged. The existing wire constructor still handles each component; failure is atomic and final correspondence is computed against the original input. No single-edge fallback or new surface solver is added. This is not a global collision detector.
